# Вебчат

Приложение для получения и обработки сообщений от клиента.

## Использование
### `Запуск`
1. Запустите сервер ```python server.py```
2. Запустите клиент ```python client.py```
3. Введите в клиенте желаемое имя пользователя
4. Наслаждайтесь общением в групповом чате

### `Список команд`
1. ```/p <user> <message>``` - отправить пользователю user приватное сообщение
2. ```/report <user>``` - пожаловаться на пользователя
3. ```/quit``` - завершить подключение к серверу
